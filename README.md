## Turf Management System

A smart, campus-exclusive platform for sports ground bookings and team formation.

### Getting Started

This Flutter application requires:
- Flutter SDK 3.0+
- Android SDK
- Firebase project for push notifications

### Setup

1. Install dependencies:
```bash
flutter pub get
```

2. Configure Firebase:
- Add `google-services.json` to `android/app/`
- Update API endpoint in `lib/services/api_service.dart`

3. Run the app:
```bash
flutter run
```

### Features

- User authentication
- Ground booking system
- Team management
- Push notifications
- Queue management

For detailed setup instructions, see the main [README.md](../README.md) and [INSTALLATION.md](../docs/INSTALLATION.md).
