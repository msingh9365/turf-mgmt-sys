# EndGame - Turf Management & Sports Networking System

This is the **frontend** for a proximity-based sports networking and turf management platform.  
The goal is to create a smart, campus-exclusive system that simplifies sports ground bookings and encourages team formation — making campus sports more organized, inclusive, and engaging.

---

## 🧩 Tech Stack
- **Framework:** Flutter (Dart)
- **Platform:** Android (tested on OnePlus Nord 5)
- **UI Toolkit:** Material Design with custom color themes
- **Tools:** VS Code, GitHub, Android Studio (SDK)

---

## 🎨 Frontend Overview
The frontend is responsible for:
- Designing and implementing **Login** and **Sign-Up** screens.
- Creating a smooth, responsive UI with a dark green gradient theme.
- Ensuring user-friendly navigation and scalability for future modules.
- Collaborating with backend APIs for authentication and data integration (upcoming).
